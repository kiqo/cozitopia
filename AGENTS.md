# Agent Guidelines

## Branch naming

Name every branch `<feature>-<what-is-changed>`, `fix-<feature>-<bug-details>` or `<type>-<what-is-changed>` in lowercase kebab-case.

Examples:
- `checklist-add-support-for-assignee-import`
- `fix-checklist-assign-all-without-homies`
- `repo-add-apache-license`

Top-level features: `checklist`, `calendar`, `homes`, `members`, `auth`, `profile`.

Types for changes that belong to no feature: `repo`, `ci`, `docs`, `build`.
